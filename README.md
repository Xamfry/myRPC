# myRPC

myRPC - учебный клиент-серверный проект на языке C.

Проект состоит из двух программ:

- myRPC-client — консольный клиент;
- myRPC-server — серверная программа-демон.

Клиент отправляет серверу имя пользователя и команду Bash.
Сервер проверяет пользователя по whitelist.
Если пользователь разрешён, сервер выполняет команду.
Результат возвращается клиенту.

## Основные возможности

- работа через сокеты;
- поддержка stream и dgram режима;
- чтение конфигурации из файлов;
- whitelist пользователей;
- запуск сервера как демона;
- обработка сигналов;
- логирование через syslog или файл;
- сборка через Makefile;
- подготовка deb-пакетов;
- тестирование через CI/CD.

## Структура проекта

```text
src/client/   исходный код клиента
src/server/   исходный код сервера
src/common/   общий код
config/       примеры конфигурации
docs/         документация и диаграммы
scripts/      скрипты сборки и установки
tests/        тесты
ci/           скрипты CI/CD
debian/       файлы для deb-пакетов
```
